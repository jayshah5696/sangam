# Workspace Home comparison

Evidence for [Sangam PR #394](https://github.com/jayshah5696/sangam/pull/394), addressing issue #375.

Before: main at `bbe647d`.
After: `be6e67e68be10ffe5adb79c2848c48634f09290f`.

Each isolated instance was seeded with the same four recent documents, one project and an empty Inbox. Project selection was reset to Workspace. Fonts were ready before capture, animations were disabled and images were captured at CSS pixel scale without editing.

Desktop uses Chromium at 1440 × 900. Mobile uses Chromium with the Pixel 7 user agent, device scale factor, `isMobile: true`, `hasTouch: true` and a 390 × 844 viewport.

Open `show-me-home.html` alongside `comparison.js` and the four PNG files to switch between desktop and mobile comparisons.

These review artifacts are stored separately from the application PR.
