4. Architectural Solutions Implemented

1. Durable Audit Group-Commit Worker

Located in src/sangam/activity.py

  • Dedicated background commit worker thread with single open SQLite connection.
  • Bounded in-memory queue (max 5000 items, 16MB buffer) with backpressure condition.
  • Drains batches up to 250 rows in a single BEGIN IMMEDIATE / COMMIT transaction.
  • Caller threads await completion via concurrent.futures.Future, guaranteeing zero-loss durable persistence with PRAGMA synchronous = FULL.

2. Narrow Scoped Keyed Creation Locks

Located in src/sangam/mutations.py

  • Replaced coarse global _creation_lock with ref-counted locks keyed on (actor_id, idempotency_key).
  • Multiple concurrent agents or users creating separate documents execute concurrently without serializing across the workspace.
  • Guarantees duplicate-suppression safety for identical client retry tokens without workspace-wide locks.

3. Event Loop Offloading for ChatKit

Located in src/sangam/chat_store.py

  • Wrapped synchronous SQLite operations across all 11 ChatKit store methods with asyncio.to_thread.
  • Prevents thread-blocking I/O on FastAPI's main asyncio event loop during chat streaming or message retrieval.

4. Operator Readiness Probe & Clean Lifespan

Located in src/sangam/readiness.py & src/sangam/api.py

  • Readiness probe verifies background worker health: reports audit_worker_unhealthy if worker thread terminates.
  • FastAPI lifespan context manager flushes and cleanly shuts down the commit worker on application termination.
