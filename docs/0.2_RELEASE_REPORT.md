## Executive decision

Sangam 0.2.0 is released. The UX redesign, accessibility dialog upgrades,
Midnight theme defaults, 2-tier settings information architecture, responsive
PDF research controls, security dependency upgrades, and documentation assets
are merged into protected `main`. The `v0.2.0` tag points to the merge commit
above, and the public release contains a signed multi-platform application image
plus attested Python artifacts and checksums.

The release is suitable for a technically capable operator to deploy privately
by immutable image digest. It is not a claim that a particular production
instance has passed Cloudflare Access, ChatKit domain registration, provider,
monitoring, or off-host restore acceptance. Those checks require the
deployment's credentials, hostnames, identities, storage, and failure domains
and remain explicit operator gates.

## What changed in 0.2.0

1. **Native Dark Theme Default**: Set Midnight near-black palette as default
   theme (`#08090a` dark background, `#7170ff` indigo accent) with refined
   semantic typography and 150ms transitions.
2. **Accessible Dialogs & Focus Trapping**: Separated `ActionMenu`
   (`role="menu"`) and `ActionDialog` (`role="dialog"`, `aria-modal="true"`,
   DOM order focus cycling, synchronous focus restoration).
3. **Chat Context & Switch Notice**: Persistent `ChatContextBanner` in ChatKit
   showing document title, revision hash snippet, and selected character count,
   plus real-time document switch alerts.
4. **Actionable Empty Workspace**: Direct CTAs to create Markdown/HTML files or
   import PDFs when starting in an empty workspace or empty explorer.
5. **Responsive PDF Research Toolbar**: Wrapped action labels in
   `.pdf-action-text` with `<600px` breakpoint rules to eliminate horizontal
   overflow.
6. **2-Tier Settings Architecture**: Divided settings into **Workspace
   Preferences** and **Operations & AI** with progressive disclosure
   (`<details>`) for agent permissions.
7. **Split-Editor Policy**: Enforced minimum split dimensions
   (`minimumHorizontalGroupWidth: 420px`, `minimumVerticalGroupHeight: 300px`).
8. **Security & Vulnerability Hardening**: Upgraded `cryptography` (50.0.0),
   `pypdf` (6.15.0), and base image security packages. Removed build-time
   binaries from final runtime layers.
