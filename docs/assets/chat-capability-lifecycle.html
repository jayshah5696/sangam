Controls that do not depend on model prose

Before run

Least-visible tools

The resolver intersects principal authority, resource scope, entry point, content type, model support, and pinned versions.

Before effect

Exact review

The user sees material arguments. The decision names one stored digest, requester, capability version, and expiry.

At execution

Current policy

The server rechecks authorization and revision state, then calls the same application service used by the normal API.

On failure

Convergent retry

The reserved operation key survives connection loss. Safe retries return or recover the original resource instead of duplicating it.

On retry

Original meaning

Document, revision, bounded selection, model, and capability versions come from the original turn context.

For review

Content-off evidence

Run and tool metadata include status, latency, usage, citations, IDs, and safe error classes without copying ordinary content.

Always inside the boundary

  • WorkspaceAccessService authorization and attribution
  • revision-pinned proposals for existing documents
  • SQLite identity, run, decision, effect, and resource records
  • strict schemas and bounded results

Deliberately absent

  • direct browser mutations for agent effects
  • generic network, shell, filesystem, SQL, or credential tools
  • prompt-only authorization or approval
  • a broker, workflow service, Redis, MCP server, or second deployment process
