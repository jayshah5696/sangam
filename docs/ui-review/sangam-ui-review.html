Mobile proposal
Use a bottom navigation bar for Files, Search, Chat, and Settings. Open the file tree as a drawer. Keep the editor toolbar to three primary actions and move secondary actions into More.

Responsive rules

• No page-level horizontal scrolling
• Minimum 44px touch targets
• Inspector becomes a sheet or drawer
• Tabs scroll horizontally without changing widths
• Chat composer stays visible above the keyboard
• Preserve focus when drawers close
