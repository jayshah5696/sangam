UX Architecture Blueprint

Agent Token Experience & Clarity Redesign

A human-centered overhaul that solves zombie row proliferation, eliminates cryptographic confusion, and provides distinct, intuitive workflows for renewing vs rotating credentials.

1. Why the Previous Flow Was Disorienting

The Previous Experience

  • ✕
    Silent 1-Click Rotation: Clicking "Rotate" instantly revoked the old key and created a new one without asking any questions or explaining what happened.
  • ✕
    Zombie Duplicate Rows: Revoked tokens remained directly inside the main list. Rotating 3 times created 4 identical-looking rows with confusing "Revoked" timestamps.
  • ✕
    Action Conflict in Edit Window: Having both Save token and Rotate secret instead in the same dialog forced users to guess which one extends the token.
  • ✕
    Cryptographic Jargon: Terminology like "Edit token authority" and "Rotate secret" obscured the user's practical goal: "Make my agent work again."

The Redesigned UX

  • ✓
    One-Click "Renew Token" on Expired Rows: Directly opens a focused renewal modal pre-set to +7 days. The user just clicks "Renew token".
  • ✓
    Collapsible Revocation History: Main list displays ONLY active or expired tokens. Historical predecessors are cleanly grouped under an expandable drawer.
  • ✓
    Single Unambiguous Save Action: No conflicting "Rotate" button inside the Edit/Renew modal. Exactly one clear primary action per window.
  • ✓
    Dedicated Rotate Modal with Warning: Clicking Rotate opens a modal explaining that existing runners will be invalidated, with a new duration selector.

2. Plain Human Language vs. Cryptographic Jargon

User Intent Confusing Tech Jargon (Removed) Clear Human Language (Adopted) What Actually Happens Under the Hood
Token expired, want agent to work Rotate secret instead / Edit authority Renew token Keeps existing secret key; pushes expiration date forward. Agent runner `.env` does not need to change.
Key leaked or need new secret Silent 1-click Rotate button Rotate key... (with warning modal) Invalidates previous secret; issues brand new raw secret with one-time copy modal.
Cleaning up old tokens Multiple identical rows in same list ▾ Inactive & rotated tokens (3 predecessors) Old predecessors tucked away; main screen stays focused on active runners.
